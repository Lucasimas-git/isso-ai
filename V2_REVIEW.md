# 5. SEÇÃO STICKY — CAMPO / SOCIETY / FUTSAL

A ideia técnica pode permanecer, mas a execução atual precisa melhorar muito.

Hoje a seção ocupa espaço demais para pouca informação.

Redesenhe.

Objetivo:

Criar uma experiência visual interessante em que o produto realmente seja protagonista.

Sugestão:

- uma chuteira grande ou fotografia de produto fica sticky;
- conforme o scroll muda:
  CAMPO
  SOCIETY
  FUTSAL
- cada etapa pode alterar texto, detalhe visual, imagem ou enquadramento;
- as diferenças precisam ser perceptíveis;
- a experiência deve parecer intencional, não uma demonstração técnica.

IMPORTANTE:

Reduza significativamente a altura dessa experiência.

Não utilizar aproximadamente uma viewport inteira apenas para cada palavra.

A seção deve comunicar as três modalidades de forma mais rápida.

Se necessário, utilize aproximadamente 150–220vh no total, não várias telas excessivas.

Em tablets e mobile, NÃO force comportamento sticky complexo.

Até aproximadamente 900–1024px, prefira uma versão simplificada, fluida e vertical se isso melhorar a experiência.

Performance e usabilidade são mais importantes que demonstrar tecnologia.
